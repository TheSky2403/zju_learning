第一次小测的反思与经验：
小测题目较简单，平时有听课把作业完全搞懂就肯定没问题
但自己做的一坨，说明自己这段时间学习是有问题的，比如第四问不独立肯定不能把两个P分开写，但脑子一团麻，说明根本没有把这些东西理的很清楚，状态也有问题。
课还是要好好听一下，上课内容比课本更难，实在太无聊也没办法。但作业必须要好好写，先想一下大致思路，然后可以问GPT，但注意在GPT辅助下必须把题目完全搞清楚，而不是只抄个答案糊弄过去。这点务必要做到。其他课程也是如此。
把作业搞清楚就完全足够，实在要准备也可以做下去年的小测，比如这次小测就跟去年第一次小测差不多，不做也没关系，但只做小测不弄清楚作业肯定不行。
